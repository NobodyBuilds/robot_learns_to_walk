# Robot Learns to Walk

A 2D legged robot learns to walk in a simulated environment using deep reinforcement learning. The project uses a PPO implementation and [noRender](https://github.com/NobodyBuilds/noRender) for rendering.

The PPO implementation is part of the related [deep_reinforcement_learning](https://github.com/NobodyBuilds/deep_reinforcement_learning) project.
